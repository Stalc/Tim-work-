# Two-site live mirroring demo

Этот репозиторий содержит два изолированных FastAPI-приложения:

- `source_app` — основной сайт, куда приходят изменения.
- `mirror_app` — зеркало, которое получает первоначальный снимок данных и затем слушает поток событий (Server-Sent Events) для мгновенной синхронизации с минимальной задержкой.

## Быстрый запуск

1. Установите зависимости (Python 3.11+):

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Запустите источник (порт 8000):

   ```bash
   uvicorn source_app.main:app --reload --port 8000
   ```

3. Запустите зеркало (порт 8001). При необходимости переопределите `SOURCE_API_URL` адресом источника:

   ```bash
   SOURCE_API_URL=http://localhost:8000 uvicorn mirror_app.main:app --reload --port 8001
   ```

4. Создайте данные на источнике и убедитесь, что зеркало их подхватывает:

   ```bash
   curl -X POST http://localhost:8000/items -H "Content-Type: application/json" \
        -d '{"title":"Новость","body":"Первое событие"}'

   curl http://localhost:8001/items
   ```

## Как работает синхронизация

- Источник хранит данные в памяти и отдает обновления через SSE-эндпоинт `/stream`.
- Зеркало при старте запрашивает `/items` для первичной загрузки, после чего держит открытое SSE-соединение и применяет каждое событие к своему локальному состоянию.
- При обрыве соединения зеркало повторяет попытку каждые ~1 секунду, сохраняя минимальную задержку.

## Расширения

- Замените in-memory хранилище на базу данных, если нужен персистентный контент.
- Добавьте подпись/аутентификацию SSE-потока, если требуется защита канала.
- Если нужно двунаправленное обновление, можно завести второй поток событий от зеркала к источнику.
